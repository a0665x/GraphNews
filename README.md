# GraphNews / 新聞關聯觀測台

真實新聞搜尋、3D 力導向圖與持久 SQLite 快取。Python 3.10+ 標準函式庫即可執行，沒有合成資料、資料庫服務或 Python 套件安裝需求。

## 開發者與新 session 入口

先讀 [spec/PROJECT_MAP.md](spec/PROJECT_MAP.md)，依任務進入架構、來源／快取、資料、UI、API、啟動或測試文件，再視需要讀深層 references。使用 `$project-spec-onboarding` 時也由此入口開始。

## 安裝與啟動

需要 Git、Python 3.10 以上，以及支援 WebGL 的現代瀏覽器。搜尋時需能連線到新聞來源；免費來源不需要 API key。前端圖形庫已內附，不需要 npm 安裝或建置。Node.js 只用於執行前端測試。

1. 下載專案並進入目錄：

   ```bash
   git clone https://github.com/a0665x/GraphNews.git
   cd GraphNews
   ```

2. 確認 Python 版本並啟動：

   ```bash
   python3 --version
   python3 server.py
   ```

3. 在瀏覽器開啟 http://127.0.0.1:8765，保持終端執行。停止服務按 `Ctrl+C`；下次在同一目錄重新執行 `python3 server.py` 即可讀取既有 DB。

Windows 可將上述 `python3` 換成 `py -3`。

開啟 http://127.0.0.1:8765。修改程式後重啟 server 並重新整理頁面。不要直接開啟 HTML。圖譜使用內附 3d-force-graph 1.80.1，需要 WebGL；若 3D 無法啟動，搜尋與清單仍可使用。

- Google／Yahoo 使用關鍵字，不會把大寫詞或公司名稱自動轉換成股票代碼。Massive 只使用明確填寫的股票代碼，先過濾不合法格式；混合搜尋未填代碼時會略過 Massive，不阻止免費來源。
- 日期設定提供「自訂日期／快速區間」滑塊切換。自訂模式預設最近 7 天，可手動指定 UTC 起迄日；快速模式提供 3／6／9／12 個月，以今天（UTC）為結束日，開始搜尋時重新計算，避免頁面跨日後使用舊日期。結束日包含在內，單次最多 366 天。
- 快速區間按日曆月回推，月底以目標月份最後一天為準；起日使用回推日的次日，讓整段含結束日的區間不超過 366 天。例如 2026-10-28 的近 3 個月為 2026-07-29 至 2026-10-28。切回自訂會還原先前手填日期；載回快照只恢復圖譜與其時間資訊，不覆寫左側正在編輯的搜尋日期。
- 366 天是本程式的單次查詢限制，不是所有來源的歷史保存上限。Massive 新聞的授權範圍依方案而異，參見 [官方歷史新聞說明](https://massive.com/knowledge-base/article/how-far-back-does-massives-news-and-sentiment-data-go)。Google／Yahoo RSS 不保證完整歷史；快速區間不保證全量取得，長區間仍受來源授權、分頁及每次請求預算限制，請查看每個來源的覆蓋／缺口狀態。
- Massive key 可在畫面填入，或於伺服器環境設定 `MASSIVE_API_KEY`。欄位旁的「?」可開啟取得方式說明，並直接連到 [Massive Dashboard](https://massive.com/dashboard)；註冊／登入後複製 API key 貼回欄位即可。預設勾選「記住此瀏覽器的 Massive key」後，Key 會存入目前網站的瀏覽器 `localStorage`，重新開啟時自動帶入。這不是加密憑證庫；取消勾選或按「清除已記住的 key」可移除保存值。Key 不寫入新聞 DB、日誌或匯出檔。伺服器環境的 Key 不會回傳給瀏覽器。
- 一個來源完成就更新圖譜，不等待其他來源。進度條顯示已完成來源比例（不是虛構下載百分比）；每個來源各一列，隨分頁即時更新「DB／新增／合計」。組成條以來源顏色區分，條紋是 DB 既有、實色是本次新增。錯誤與覆蓋細節可展開查看；HTTP 429 會依 Retry-After 暫停再請求。
- 「停止等待」中止瀏覽器等待；已開始的伺服器補抓可能繼續完成並寫入 DB。

服務預設監聽 `0.0.0.0:8765`，主機本身仍可開啟 `http://127.0.0.1:8765`。同網路的手機請使用 `http://主機的網路IP:8765`，不要輸入 `0.0.0.0`；主機 IP 可用 `ip -4 -brief address` 查詢。若有防火牆，需允許該網路連入 TCP 8765。修改程式後須重啟服務才會生效。

`PORT` 可修改 HTTP 連接埠。這是受信任區域網路／tailnet 的共用資料服務，不提供多使用者帳號隔離。

## 第一次搜尋與操作

1. 輸入新聞關鍵字（例如「晶片製造」或 `Tesla`），選擇 Google／Yahoo 和 UTC 日期範圍，再按搜尋。
2. 要使用 Massive 時，另外勾選 Massive、填入明確股票代碼及自己的 API key；也可先設定 `MASSIVE_API_KEY` 環境變數再啟動。只搜尋免費來源時不需填寫。
3. 查看每個來源的進度與「DB／新增／合計」。來源出錯時展開狀態查看原因；其他來源仍可完成。
4. 在 3D 圖上拖曳節點觀察彈簧互動，拖曳背景旋轉、滾輪縮放；滑鼠移到節點查看預覽與相鄰關係，點選可閱讀新聞詳情及開啟原文。
5. 用圖面來源勾選框切換顯示；預設混合關聯，勾選「依來源分組」可分開觀察。
6. 切至「時間軸 × Channel」查看事件分類，使用「管理」建立自訂規則。
7. 按「儲存目前圖譜到 DB」，下次可從「已儲存圖譜」還原。新聞快取則會在搜尋時自動保存。

## 語言、版面與節點資料

右上角可切換繁體中文／English，偏好會在目前瀏覽器保留。切換的是操作介面；新聞原文、關聯證據、自訂關鍵字及 JSON 值不會被翻譯。來源返回的錯誤訊息維持原文。

桌面版可拖曳搜尋面板／圖面、圖面／新聞面板之間的分隔線調整寬度；分隔線可用 Tab 聚焦後按左右方向鍵調整，Home 回到預設寬度。寬度會記住，縮小視窗時限制最小圖面空間。窄螢幕仍使用可開關的搜尋及新聞面板。

點選新聞後，詳情下方的「節點資料與標準 Schema」提供樹狀 JSON。預設只顯示欄位名稱、型別及子項數，逐層展開才載入值。可查看標準文章欄位、目前可見的相關 edge、來源與證據，以及由選定節點延伸的路徑（父節點、深度、累積分數）。同區域可展開完整 JSON Schema v2.0；不包含 API key 或 3D 引擎內部物件。

## 進階關聯與多層探索

展開「強制更新已快取區間」下方的「進階關聯與多層探索」，滑桿會即時更新 3D／時間軸：

| 設定 | 預設與行為 |
| --- | --- |
| 來源內 edge 最低分數 | 0，保留所有已載入來源內關聯 |
| 跨來源 edge 最低分數 | 0，保留所有已載入跨來源關聯 |
| 滑鼠延伸深度 | 2，可選 1–6 層 |
| 每個節點最多延伸分支 | 4，可選 1–12 條；優先選較高分數的未走訪鄰居 |
| 從主節點起的累積門檻 | 0.25；沿路 edge 分數相乘，低於門檻停止 |

例如三條線分數為 0.9、0.8、0.7，從主節點的累積分數依序為 0.9、0.72、0.504；門檻設為 0.55 時，第三層不再延伸。採逐層走訪，避免循環；每次節點探索最多高亮 150 個節點。這是有依據連線的探索樹，不是最強路徑搜尋、因果追溯或概率。

滑桿只篩選當前載入的關聯候選，不重新抓取新聞、不遍歷整個本地 DB，也不會讓原本沒有證據的節點產生新線。降低門檻只能恢復原本載入的線。設定會記住，並隨手動快照保存；快照保存來源與 edge 門檻篩選後的關係；時間／分類隱藏的節點仍保留，讓 root 路徑能完整還原。

## 星系光暈與深度明暗

「進階關聯與多層探索」內的「星系光暈與深度明暗」可調整光暈亮度、大小、每層保留亮度及非關聯節點的亮度。預設開啟：root 的中心最亮、光暈最大，後續分支隨深度變淡；來源顏色仍保留。例：每層保留亮度設為 50%，第 0–3 層的光強依序為 100%、50%、25%、12.5%，最後依畫面合成轉為透明度。

3D 畫面中，滑鼠接近節點只預覽候選 tree，不必精準碰到小圓點；需點一下才進入確認 root 的星系模式。預覽只加淡光暈與提示，不壓暗全局，移開後自動消失。預設「黏性強度」65%，可調為 0–100%，偏好保存在瀏覽器。命中範圍依節點經相機投影後的大小計算，因此會跟隨縮放與節點距離變化；不再使用固定像素半徑。數值越高，節點外可吸附的範圍越大；0% 仍保留節點本體的選取。調滑桿時會立即重算，並短暫以虛線顯示目前 root 的範圍。相鄰候選必須明顯更接近且停留約 80 ms 才切換，按下拖拉則直接鎖定命中節點。

只有點擊確認過的星系才在滑鼠移開或放開拖拉後保留；進入星系後滑過／點選其他新聞只查看內容，不會改選 root，必須先回全局。點空白、按 Esc、按「取消固定 root」，或 5.5 秒沒有指標／滾輪／鍵盤操作時回到全局。按住節點的整段拖拉期間不會逾時，即使按住不動超過 5.5 秒也會保留；放開後重新計時。手機可直接點選／拖拉。

3D 的光暈是即時 Canvas 繪製，不是預先製作的圖片。光暈與連線在原本 WebGL render 結束的同一幀投影，使用相同相機與節點位置；切換 root 時保留舊光暈漸退、新光暈漸入，避免兩個獨立動畫迴圈的視覺錯位。返回全局時，光暈與連線用較慢的過渡淡出，同時讓背景節點及底層連線逐步回復原本亮度，約一秒恢復平衡；不會先把背景瞬間點亮。若系統啟用減少動態效果，會省略漸變。

可從吸附範圍內按住拖拉真正的力導向節點，拖拉方向沿相機平面，保留按下時的游標偏移；相鄰節點照常受到彈簧牽動。拖拉期間固定操作的節點並暫停鏡頭旋轉，但拖拉本身不確認 root，放開或取消後恢復。空白處拖曳仍旋轉視角。按住 Ctrl＋滑鼠左鍵拖拉會平移相機與視角中心（即使從節點上按下也優先平移），不搬動任何資料節點、不切換 root、不取消星系。平移期間保留效果並暫停閒置回復，放開後才重新計時。光暈本身不攔截指標事件，也不更改來源分數或原本的關聯距離設定。時間軸的密度格與逐篇節點共用 3D 選定的 root／搜尋 roots，依深度漸淡。密度格保留篇數與來源色條，★ 表示 root，命中比例與 d 深度以格內最淺關聯為準，分類旁列出相關篇數。沒有閃爍或自動脈衝動畫。設定保存在瀏覽器，也會隨圖譜快照與 JSON 匯出保存；固定的單 root 或關鍵字多 roots 會寫入快照並可還原。

## 時間大小焦點

圖譜底部新增日期滑桿，左側是最舊日期、右側是最新日期，範圍來自本次已載入新聞的搜尋日期；12 個月區間以月份標記。未送出的左側日期草稿不改動既有圖譜的時間範圍，執行新搜尋後會同步。

拖動滑桿會即時放大接近焦點日期的新聞，最接近者半徑最高為原本 2 倍，越遠逐漸回到原大小；未知日期維持原大小。設定中的「依時間距離調整節點大小」可關閉。這不篩掉新聞、不改關聯分數／位置／視角，也不重新呼叫 API。逐篇時間軸也會調整圓點大小；密度格仍以篇數顯示。吸附範圍會依實際節點大小與相機縮放調整。

開關及焦點日期會保存在瀏覽器，也包含在匯出與圖譜快照的 `view.time_focus = {enabled, date}`。日期使用 UTC，還原時限制於該圖譜日期範圍。舊快照沒有這個欄位時沿用固定大小。此滑桿與時間軸的「發布截止」分開，兩者可以同時使用。

## 圖上來源與圖譜快照

搜尋來源決定向誰抓資料；圖面上的勾選框只決定目前顯示誰，不會觸發網路請求。

- Google：綠色；Yahoo：紫色；Massive：藍色。圖例有來源名稱與數量，可即時勾選。
- 預設混合目前勾選來源，自動加入有證據的跨來源關聯（金色）。來源內關係獨立計算、保留，不會被跨來源連線名額排擠。跨來源線使用較弱的彈簧力；切換來源時保存節點座標與來源內線段目前長度，盡量維持既有空間關係，但不保證物理模擬距離完全不變。
- 勾選「依來源分組」可回到獨立區域。相同 URL 在混合模式合併、分組模式分開；多來源節點採目前勾選順序中的第一個來源顏色，預覽列出全部來源。
- 圖面上限 800 節點，以輪流分配各來源的方式避免單一來源占滿。切換來源會即時重新取樣和顯示該來源已有的資料。

「儲存目前圖譜到 DB」保存目前來源／edge 門檻篩選後的文章與關係（含暫被時間／分類隱藏的節點，以保留 root 路徑）、勾選來源、分組／時間軸模式、節點位置與當時的 channel 定義、篩選及發布截止日；資料依來源分開存於 `snapshot_articles`、`snapshot_relations`，跨來源關係使用 `cross` 分區。可從「已儲存圖譜」載回，重啟後仍可使用；不會重新推論已存關係。每次儲存新增一份快照，不覆蓋舊快照。

自動快取用於節省來源請求；手動快照用於保存當下探索結果，兩者分開。手動儲存不會將任何日期誤標為 API 已抓齊，也不會保存 API key。

## 時間軸 × Channel

點擊「時間軸 × Channel」預設顯示「日期 × 分類」密度格：每個分類固定高度，每個 UTC 日期一格，數字表示新聞篇數，下方色條表示來源組成。點格子會在新聞詳情區展開該格所有文章，點文章查看全文連結與 JSON。密度格只顯示有資料的分類，避免空白泳道及大量節點堆疊。沒有選定 root 時，滑鼠移到格子可預覽格內前 10 篇新聞的關聯；已有 root／搜尋 roots 時，保持同一森林，不會被 hover 換掉。切換分類／發布截止只控制顯示，保留隱藏 root 的深度與路徑，切回 3D 仍是原本的選取。

「呈現方式」可切回逐篇節點，保留精確發布時間、原有跨泳道關係及與 3D 相同的多層高亮設定。兩種模式都可橫向捲動、縮放；顏色表示新聞來源。可選單一 channel、拖動發布截止日或按播放；日期先後和連線都不代表因果，也不是「當時已知資訊」的歷史回測。

預設 channel：晶片製造、生產／供應鏈、財務報告、股價／交易、產品／技術、政策／法規、其他／未分類。一篇新聞可以命中多個 channel，主要分類按命中分數選擇（標題每個詞 3 分、摘要 1 分；同詞不重複計分），同分依定義順序。這是可解釋的關鍵字規則，不是模型機率。詳情會顯示所有分類及命中的標題／摘要文字。分類本身不會憑空新增連線。

在時間軸的「管理」或側欄「分類 Channel」新增自訂名稱、逗號／換行分隔的關鍵字、任一／全部比對及顏色。可編輯或移除自訂分類，會保存至 SQLite `channels` 表並重新分類目前資料；重新啟動後仍保留。預設分類唯讀，自訂最多 25 個，每個最多 30 個關鍵字，使用字面比對而不是執行正規表示式。

快照保留當時的分類依據與定義；之後改名／移除 channel 不會修改已存快照。載入快照後可選「用最新規則重新分類」，再另存新快照。舊版快照沒有分類資料時會依目前規則補上分類，不會重新計算關係。

## 本地 DB 與缺口補抓

啟動時自動建立 **`data/news-atlas.sqlite3`**。每次搜尋更新同一份 DB，重啟不會清空。`NEWS_ATLAS_DB` 可指定另一個檔案位置。內容與備份方式見 [data/README.md](data/README.md)。DB 不透過靜態 HTTP 服務對外提供。

覆蓋依「來源＋實際查詢＋語系／轉接器版本＋UTC 日期」記錄，不從最早／最晚文章日期猜測完整性。例如第一次已查齊 10/01–10/07，下一次要求 10/05–10/10，快取仍有效時只補 10/08–10/10；資料和覆蓋一起以交易寫入 DB。

| 情況 | 行為 |
| --- | --- |
| Massive 成功翻完所有分頁 | 記錄 `complete`，含成功回傳零篇的區間；只表示該 API 在當時可存取的結果已讀完 |
| Massive 後續分頁失敗 | 保存已取得文章；升冪分頁已讀完的完整日期可重用，最後未讀完的日期仍是缺口 |
| RSS 未達筆數上限 | 記錄 `snapshot`，只是當次 RSS 索引快照，不能宣稱歷史完整 |
| RSS 達 100 筆 | 自動拆小日期區間；單日仍達上限則不標已覆蓋 |
| 限流、逾時或請求預算用完 | 保存已取得部分，保留缺口並顯示原因 |
| 重複／重疊搜尋 | 讀取已有文章，僅補缺口或過期日期；相同來源查詢會序列化補抓，避免重複請求 |

Massive 歷史完整日期快取有效 24 小時；UTC 當日與 RSS 快照有效 5 分鐘，以便補上新發／晚到的新聞。到期只更新相應日期。勾選「強制更新已快取區間」可立即重新查詢，但仍遵守來源限流。每個來源每次最多 12 次請求／約 90 秒預算，每次網路讀取逾時 15 秒；耗盡時顯示未完成，不偽裝成已抓齊。高流量單日若仍超過預算，會保留缺口供後續處理。

DB 採 URL 去除常見追蹤參數後的穩定 ID 去重；同網址跨來源在圖面合併並保留 `origins`，DB 保留各來源觀測。Google 轉址 URL 與原始網站 URL 不一定能合併，因此同一報導仍可能有多個節點。無有效發布時間的資料不放入指定日期結果。

## 來源

- **Google 新聞 RSS**：文字關鍵字，日期運算子加上本地 UTC 過濾。索引與 RSS 不保證全部歷史新聞。
- **Yahoo Finance**：透過 Google 新聞 RSS 限定 `site:finance.yahoo.com`，資料記錄 `source.via: google_news_rss`，不是 Yahoo 官方付費 API。
- **Massive**：官方 `/v2/reference/news`、`published_utc.gte/lt`、`next_url` 分頁。每頁最多 1000 筆；授權、歷史範圍與更新頻率依來源／方案。參考 [官方新聞 API](https://massive.com/docs/rest/stocks/news) 與 [驗證方式](https://massive.com/docs/rest/quickstart)。

### 語言、國家與新聞涵蓋範圍

目前來源參數固定在伺服器端，不依開啟 WebUI 的手機／電腦國家或介面語言自動切換：Google RSS 使用 `hl=zh-TW`、`gl=TW`、`ceid=TW:zh-Hant`；Yahoo 使用 Google RSS 的 `en-US`／`US`／`US:en`，並限定 `site:finance.yahoo.com`；Massive 使用股票代碼查詢其供應商資料。請求由執行 server 的主機發出，不帶使用者 Google 帳號設定或定位。

搜尋結果會受到搜尋詞語言、地區版本、出版商報導／索引涵蓋及 RSS 筆數限制影響。新聞篇數不等於各國的實際曝光量，也不能當成完整的全球報導統計。Google 官方亦說明新聞呈現受地區、語言與位置設定影響，見 [How news works](https://www.google.com/intl/en_us/search/howsearchworks/how-news-works/)。目前不提供新聞地區選單；右上角語言選單只翻譯介面。

## 統一 schema 與可解釋關聯

[JSON Schema v2](schema/news-atlas.schema.json) 定義所有來源共用的文章與關聯格式。分組檢視的節點 ID 為 `來源::文章ID`，`article_id` 保留原始穩定 ID；DB 文章仍使用原始 ID。原有文章欄位保留，新增 `entities`、`topics`、`analysis_version`、`origins`，並包含 `channels`、`primary_channel`、`channel_version`。不會把使用者搜尋詞直接當成文章事實。

- `symbols`：來源明確提供的股票代碼，免費來源通常為空。
- `entities`：來源標註或文章標題／摘要中的公司別名，例如 Tesla／特斯拉／TSLA；每筆帶 `method`、`field`（文字辨識時）與原文命中 `evidence`。
- `shared_entity`：共同實體，限 30 天內。可連接 Massive 來源代碼與免費新聞文字。
- `shared_topic`：共同主題且標題至少兩個共同詞、Jaccard 相似度至少 0.18，限 7 天內。
- `similar_title`：至少四個共同標題詞且 Jaccard 至少 0.5，限 3 天內。

規則字典在 `news_atlas/model.py`，涵蓋常見科技股中英文公司名與六種主題；不是通用 AI 語意模型，未涵蓋名稱、模糊詞彙或不同語言仍可能漏連／誤連。未找到足夠依據會保留獨立節點。來源內每篇最多六條優先關聯；跨來源另用每來源配對最多兩條／節點的預算，避免取代原本連線或形成密網。線條與分數不是因果、機率或投資訊號。

點選新聞可查看相關文章與每條線的文字證據。圖面與 JSON 匯出最多顯示 800 個節點，畫面標示總數，已抓取的完整資料留在 DB；縮短日期可深入較早新聞。API key 不包含在匯出中。

## 專案結構

- `server.py`：HTTP／串流事件、輸入驗證、組合圖譜。
- `news_atlas/providers.py`：來源請求、日期界線、分頁、上限、錯誤分類。
- `news_atlas/storage.py`：SQLite、日期覆蓋／新鮮度、限流記錄。
- `news_atlas/search.py`：快取重用與補抓協調。
- `news_atlas/model.py`：標準化、去重、實體辨識與關聯證據。
- `news_atlas/channels.py`：預設分類、規則驗證、多標籤分類與文字依據。
- `news_atlas/snapshots.py`：手動快照驗證與來源分區。
- `dist/`：網頁、互動程式及離線圖形庫；`graph-view.js` 負責來源切換與分組，`timeline.js` 負責時間軸／密度格與 SVG 互動，`explorer-ui.js` 負責面板尺寸、瀏覽器偏好及 JSON 樹，`i18n.js` 負責介面語言。
- `data/`：本地持久資料；`tests/`：隔離測試，不將測試文章寫入正式 DB。

## Docker 網路說明

本專案直接使用 Python HTTP server 與 SQLite 檔案，沒有 Dockerfile／Compose 設定，也不會建立 Docker bridge 或 `br-*` 網路介面。執行 `python3 server.py` 即可，不需要新增容器網路。

若另外為其他專案使用 Compose，固定 project name 可讓同一專案沿用相同命名的網路；需要跨專案共用時，可指定已建立的 `external` network，避免每個專案各建一個預設網路。但共用網路也代表那些服務可互相連線，不應任意合併所有專案。詳細設定見 [Docker 官方網路文件](https://docs.docker.com/compose/how-tos/networking/)。

## Tailscale

先執行 server，再於另一終端執行 `bash start-tailscale.sh`。腳本檢查 8443 未被使用後，反向代理至本機 8765。停止：`tailscale serve --https=8443 off`。若使用自訂 PORT，需相應調整代理。手機需連線到同一 tailnet 並有存取權。首次使用時，請從另一台已連線的裝置確認實際網址可開啟。

## 圖內關鍵字、多星系與 Swagger API

「圖上顯示來源 · 即時篩選」同一外框內可輸入關鍵字和 Top N（1–10）。按紙飛機圖示的「Search」後，依目前圖內文章的標題、摘要、代碼、實體、主題與分類命中，固定最相關的 N 個 roots 並同時畫出探索樹；未命中不補假資料。多星系不會因滑過其他節點或閒置而重選，點圖中空白處取消後才能重新選取。各樹仍遵守關聯門檻，可共享真實節點；不是全 DB／全網搜尋。節點大小可依底部時間焦點放大；設定可取消，詳見「時間大小焦點」。

API 文件：http://127.0.0.1:8765/docs · OpenAPI：http://127.0.0.1:8765/openapi.json · 資料 schema：http://127.0.0.1:8765/api/schema

完整的可視化功能、schema 產生流程、20 個 API 操作與 MCP 包裝方式見 [docs/API.md](docs/API.md)。包含單一 JSON 新聞搜尋、唯讀快取／缺口、文章標準化、建圖／篩選、多 roots 探索、日期分類彙整和視圖驗證。Swagger 已隨專案附帶，無需 CDN 或 npm；目前尚未實作 MCP transport。更新這次 Python 功能後需重啟 server，再重新整理頁面。

圖內 Search 直接在瀏覽器對當下 runtime 新聞做文字排名並疊加星系，不發出 HTTP 請求、不提交表單、不重新抓新聞或清空節點。Search 與輸入框 Enter 都使用同一路徑，零筆命中保留現有圖譜與星系；點圖中空白處回到全局。獨立的 `/api/graph/explore` 仍供 API／MCP 客戶端使用。


以本機真實 NVDA 快取驗證「三來源圖譜 → robot」的瀏覽器回歸頁：

```bash
python3 tests/browser_runtime_search.py /tmp/graphnews-runtime-regression.html
```

以支援 WebGL 的瀏覽器開啟產生的 HTML；`document.body.dataset.qa` 顯示結果。測試資料只讀 SQLite，不呼叫新聞來源、不使用 API key、不寫回 DB。檢查 Search／Enter 不提交表單、不發出網路請求、不替換節點／連線，以及零筆命中保留圖譜；需要本機已有 NVDA 真實快取。

圖內 Search v3 提供轉圈等待、掃描／命中／roots／高亮節點數量，以及空白查詢、無節點、Top N 不合法、零筆命中、錯誤、光暈關閉／零亮度、無延伸邊、視野外 roots 等提示。來源數字是各來源可用文章數；搜尋範圍是目前顯示圖譜（最多 800 節點），不是三個來源數字相加或全部 SQLite 資料。


## 搜尋草稿自動保存

左側關鍵字、Massive 股票代碼、新聞來源勾選、強制更新選項，以及自訂日期／快速區間模式和回推月份，會在輸入或修改時即時保存至 `graphnews.searchDraft`，不必先按搜尋。重新整理後會還原；刻意清空文字或取消所有來源也會保留。快速區間仍以重新開啟時的 UTC 當日計算，自訂日期則維持原值。

圖內搜尋、來源顯示切換、時間軸／3D 操作與載入圖譜快照，不會覆寫這份搜尋草稿。圖譜的歷史查詢條件獨立存在匯出與快照 metadata。Massive key 維持既有的獨立記憶／忘記選項，不存入搜尋草稿。

設定限於同一瀏覽器、同一網站位址（origin）；切換 localhost、區網 IP、Tailscale 位址或不同連接埠會使用不同儲存空間。若儲存被禁用，介面會顯示無法保留的提示。


## 篩選框與圖內搜尋範圍

「圖上顯示來源 · 即時篩選」標題列可拖曳，也支援方向鍵移動。按「收合」只保留標題列；按「展開」恢復，按「歸位」回到原位置。位置與收合狀態保存在此瀏覽器，不修改節點、來源選擇或搜尋文字。

圖內關鍵字匹配標題、來源提供的摘要（RSS description／Massive description）、代碼、實體、主題及分類。摘要可命中，但並沒有下載或索引新聞全文。只出現在未取得的全文中的詞無法匹配；本地尚未取得的文章也不可能由圖內搜尋召回。圖內搜尋限目前顯示節點，不是全部 SQLite／整個網路。

Yahoo 來源目前限定美國英文 `finance.yahoo.com`，不包含 `tw.news.yahoo.com` 的台灣綜合新聞。欲搜尋特定產品，可先在左側 Google 來源使用產品名稱與涵蓋發布日的日期區間取得新聞；RSS 不保證收錄完整，股票代碼查詢也不保證包含所有產品活動報導。
